Good data, bad data: the residuals explorer

Below are 100 simulated observations, made in the same way as the ones in the practical. The first slider bends the relationship between x and y, and the second makes the noise get bigger as x gets bigger. Start with the "good" data and move one slider at a time: each time you change something, have a look at the four plots and then read the "What's going on?" box, which changes to explain what you are seeing. If you hover over a point you can find the same observation in all four plots.
